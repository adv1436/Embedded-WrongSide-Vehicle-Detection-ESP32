# Embedded Wrong-Side Vehicle Detection and Intelligent Traffic Signal Control Using ESP32

An intelligent traffic management system using ESP32 that detects wrong-side vehicle movement and dynamically controls traffic signals.

---

## Features

- Wrong-side vehicle detection
- Intelligent traffic signal control
- Emergency vehicle priority system
- Traffic density management
- Buzzer alert system
- Real-time lane monitoring

---

## Hardware Components

- ESP32 Dev Module
- IR Sensors
- LEDs
- Buzzer
- 4x4 Keypad
- Breadboard
- Jumper Wires

---

## Software Used

- Arduino IDE
- Embedded C

---

---

## Working Principle

1. IR sensors detect vehicle movement.
2. ESP32 analyzes vehicle direction.
3. Wrong-side movement triggers alert system.
4. Traffic signals operate dynamically.
5. Emergency lanes receive priority access.
